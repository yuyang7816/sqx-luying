# 露营租赁运营中心（管理端）

基于 Vue 3 + Vite + Element Plus，对接本仓库服务端（上下文路径 `/sqx_fast`）。

## 启动

克隆或下载后**不含** `node_modules`，需先安装依赖：

```bash
npm install
npm run dev
```

本地联调时，将 `.env.development` 中的 `VITE_API_BASE_URL` 指向本机服务端，例如：

`http://127.0.0.1:9188/sqx_fast/`

开发站点默认端口 **5173**。更详细的图文步骤见仓库根目录 [docs/管理端-运行教程.md](../docs/管理端-运行教程.md)。
