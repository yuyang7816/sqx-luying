# 服务端运行教程

按顺序做。做完一步，看到文中写的成功标志，再做下一步。

服务端是三个端里要**第一个**启动的。它没有给普通用户点的页面，只在后台一直开着，给管理端和用户端提供数据。代码在 **`luyingzulin_server`** 文件夹。

启动成功后，电脑上会多出一个一直开着的窗口。**这个窗口不能关。** 关了以后，管理端登录页的验证码会裂开，用户端首页也加载不出装备列表。

---

## 开始之前要准备什么

在自己的 Windows 电脑上安装下面三个软件。安装时勾选「添加到 PATH」或「Add to PATH」。

| 软件 | 用什么版本 | 怎样确认已经装好 |
|---|---|---|
| JDK | 1.8（也叫 Java 8） | 打开 PowerShell，输入 `java -version`，能看到 `1.8.0` |
| Maven | 3.6 或更高 | 输入 `mvn -v`，能看到 `Apache Maven 3` |
| MySQL | 8.0 | 开始菜单里能找到「MySQL 8.0 Command Line Client」 |

**Java 请安装 1.8。** 装成 11、17 或 21 时，这个服务端编译不过。下载可用 Adoptium 的 Temurin 8：https://adoptium.net/temurin/releases/?version=8

**Maven** 下载：https://maven.apache.org/download.cgi 。解压后把里面的 `bin` 文件夹加到 PATH。关掉原来的 PowerShell，再打开一个新的，`mvn -v` 才能看到版本。

**MySQL** 安装过程中会让你给 `root` 设一个密码，还会确认端口。Windows 上新装的 MySQL，端口通常是 **3306**。本地开发时，库名是 **`luyingzulin`**，连接信息写在 **`application-dev.yml`** 里（默认 `root` 账号，密码需要改成你自己安装 MySQL 时设的那个）。

**Redis 本地不是必须装的。** 当前开源配置里 `sqx.redis.open` 为 `false`，并且启动时排除了 Redisson 自动配置。按本教程用 **`dev`** 环境在本机跑起来，**可以不安装 Redis**。以后如果在配置里打开了 Redis 相关开关，再安装 Redis 5.0+ 并保持 `6379` 端口运行即可。

## 第 1 步：新建空数据库

`db/lyzl.sql` 里是表和数据，它**不会**自己创建名叫 `luyingzulin` 的库。要先建库，再导入。

1. 打开开始菜单里的 MySQL 命令行。
2. 输入你安装 MySQL 时设的 root 密码，回车。看到 `mysql>` 才算连上。
3. 把下面这一整行复制进去，回车：

```sql
CREATE DATABASE IF NOT EXISTS luyingzulin DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

4. 再输入：

```sql
SHOW DATABASES;
```

列表里有 **`luyingzulin`** 就成功了。输入 `exit` 退出。

如果提示 `Access denied`，是密码错了，用安装 MySQL 时设的那个密码重来。

---

## 第 2 步：导入数据库文件

文件位置（相对整个项目文件夹）：

**`luyingzulin_server/db/lyzl.sql`**

这一份就是完整库，里面有租赁商品、订单、商户、管理员、菜单、系统配置等。导入会覆盖同名的表，所以请导入到上一步新建的空库 **`luyingzulin`**，不要导入到别的业务库。

**用 Navicat 时：** 连接到本机 MySQL，双击打开 `luyingzulin`，菜单选「运行 SQL 文件」，选中 `luyingzulin_server/db/lyzl.sql`，编码选 UTF-8，点开始。底部显示成功即可。

**用命令行时：** 在项目根目录打开 PowerShell。项目根目录是能同时看到 `luyingzulin_server`、`luyingzulin_admin`、`luyingzulin_uniapp` 的那一层。把 `-p` 后面的密码改成你的 MySQL 密码：

```powershell
$mysql = "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe"
& $mysql -uroot -p你的密码 -P3306 --default-character-set=utf8mb4 luyingzulin -e "source $($PWD.Path -replace '\\','/')/luyingzulin_server/db/lyzl.sql"
```

如果提示找不到 `mysql.exe`，到 `C:\Program Files\MySQL\` 下面找到实际的 `mysql.exe`，把上面第一行的路径换成你的路径。

导入结束后，再执行：

```sql
USE luyingzulin;
SHOW TABLES;
```

能看到 **`rent_goods`**、**`rent_order`**、**`rent_category`**、**`merchant`**、**`sys_user`**、**`sys_menu`** 这些表，就说明导入成功。

---

## 第 3 步：让程序连接你自己的 MySQL

配置文件是普通文本，用记事本或 VS Code 都能改。改完要点保存。冒号后面那个空格要留着。

仓库默认 **`spring.profiles.active: prod`**，`prod` 里写的是远程数据库，**不适合本机练习**。本机开发请改成 **`dev`**。

1. 打开：

   **`luyingzulin_server/sqx-application/src/main/resources/application.yml`**

2. 找到下面这一段，把 `prod` 改成 **`dev`**：

```yaml
spring:
  profiles:
    active: dev
```

3. 再打开：

   **`luyingzulin_server/sqx-application/src/main/resources/application-dev.yml`**

4. 找到 `url`、`username`、`password` 这三行。`url` 里已经写着 `127.0.0.1:3306/luyingzulin`，账号一般是 `root`。**把 `password` 改成你安装 MySQL 时设的真实密码。** 保存。

5. 同一目录下的 `application.yml` 里，服务端口是 **9188**，访问路径是 **`/sqx_fast`**。这两项不用改。浏览器以后会用 `http://127.0.0.1:9188/sqx_fast/` 访问服务端。

---

## 第 4 步：启动服务端

在 **`luyingzulin_server`** 文件夹里打开 PowerShell（在文件夹空白处按住 Shift，右键，选「在终端中打开」），执行：

```powershell
mvn clean install -DskipTests
cd sqx-application
mvn spring-boot:run
```

第一行会下载依赖并编译多个模块，第一次可能要 10 到 30 分钟，窗口要一直开着。第二行进入真正的启动模块。看到这行字才算启动成功：

```text
露营租赁项目启动成功...
```

**不要关闭这个窗口。** 关闭后服务端就停了。

**用 IDEA 也可以：**

1. 用 IDEA 打开 `luyingzulin_server`（选有 `pom.xml` 的那一层）。
2. 等右下角 Maven 导入结束。Project SDK 选 **1.8**。
3. 菜单「File」→「Settings」→「Plugins」，搜索并安装 **Lombok**，然后勾选「Enable annotation processing」。很多类用了 Lombok，没装插件时会报找不到 `getXxx`。
4. 打开 `sqx-application/src/main/java/com/sqx/SqxApplication.java`，点左侧绿色三角运行。
5. 控制台同样要出现「**露营租赁项目启动成功...**」。

## 怎样算成功

浏览器打开：

http://127.0.0.1:9188/sqx_fast/doc.html

能看到 **Knife4j 接口文档**页面，里面有「租赁模块 - APP 端」「租赁模块 - 管理端」「业务模块」等分组。这个页面只是接口清单，不是管理后台，也不是用户手机上的页面。

如果这个页面打不开，只要启动日志里有「露营租赁项目启动成功...」，并且接下来管理端能打开登录页上的验证码图片，也算服务端已经就绪。

管理端登录账号来自数据库里的管理员表。很多基础库的初始账号是 **`admin`**，密码是 **`123456`**。这是**后台登录密码**，和 MySQL 的 root 密码不是同一件事。库里没有这个账号时，登录会提示账号或密码错误，要用库里实际存在的管理员。

短信、微信、支付宝、地图、图片存储这些密钥需要自己到对应官网申请，再填进管理端「系统配置」。申请入口写在 [用户端功能说明](用户端-功能说明.md) 末尾。

## 常见问题

**`java` 不是内部或外部命令，或版本不是 1.8**  
Java 没装好，或装成了更高版本。安装 Temurin 8，关掉 PowerShell 再打开，重新执行 `java -version`。

**`mvn` 不是内部或外部命令**  
Maven 的 `bin` 没有加到 PATH。加完后必须关掉 PowerShell 再开一次。

**`Access denied for user 'root'`**  
MySQL 密码和 `application-dev.yml` 里的 `password` 不一致。把 yml 里的密码改成你安装 MySQL 时设的密码，导入命令里 `-p` 后面也改成同一个密码。

**`Communications link failure`，或提示连不上 3306**  
本机 MySQL 没有启动，或端口不是 3306。先到 Windows 服务里启动 MySQL，再让配置文件里的端口和实际端口一致。

**`Unknown database 'luyingzulin'`**  
第 1 步的建库没有成功。回到命令行把 `CREATE DATABASE` 再执行一次。

**导入 SQL 时提示表已存在或中文变问号**  
请导入到空的 `luyingzulin` 库。命令里要带 `--default-character-set=utf8mb4`。用 Navicat 时，运行 SQL 文件的编码选 UTF-8。

**启动报找不到数据源，或连到了远程库**  
`application.yml` 里的 `spring.profiles.active` 仍是 `prod`。本机开发请改成 **`dev`**，并确认 `application-dev.yml` 里的库名是 `luyingzulin`。

**启动报找不到 `getXxx`、`setXxx` 或 `log`**  
IDEA 没装 Lombok，或没打开注解处理。按第 4 步安装插件后再编译。用 `mvn spring-boot:run` 时，Maven 会自己处理 Lombok，一般不会出现这个问题。

**`Port 9188 was already in use`**  
9188 端口已经被占用。把之前开着的服务端窗口关掉，或在任务管理器里结束对应的 Java 进程，然后再启动。

**在 `luyingzulin_server` 根目录直接执行 `mvn spring-boot:run` 找不到主程序**  
启动模块在子文件夹 **`sqx-application`**。先在上一级执行 `mvn clean install -DskipTests`，再进入 `sqx-application` 执行 `mvn spring-boot:run`。
