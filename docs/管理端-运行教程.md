# 管理端运行教程

按顺序做。这是**电脑浏览器**里的后台，不是手机应用。登录页标题是「**露营租赁运营中心**」。代码在 **`luyingzulin_admin`** 文件夹。

先按 [服务端运行教程](服务端-运行教程.md) 准备数据库并启动服务端。服务端窗口里要已经出现「**露营租赁项目启动成功...**」，并且那个窗口不能关。服务端没启动时，这个网站打得开，但验证码图片是裂的，登录也会失败。

---

## 开始之前要准备什么

安装 **Node.js 18 或更高**：https://nodejs.org/

建议安装 18 或 20 的长期支持版。安装时勾选添加到 PATH。安装完成后，**重新打开** PowerShell，输入：

```powershell
node -v
npm -v
```

两行都有版本号才算成功，例如 `v18.20.0` 以及 `10.x`。只看到「不是内部或外部命令」时，关掉窗口再开一次；还是没有，就重新安装 Node.js 并勾选 PATH。

浏览器使用 **Chrome** 或 **Edge**。

---

## 第 1 步：确认连的是自己电脑上的服务端

管理端自己不保存订单。你在页面上点查询、通过、保存，它都会把请求发给服务端。所以要先告诉它服务端在哪。

用记事本或 VS Code 打开 **`luyingzulin_admin/.env.development`**。开发时网页请求的就是这里的 **`VITE_API_BASE_URL`**。

文件里现在多半是指向线上的地址，例如：

```text
VITE_API_BASE_URL=https://luyingzladmin.xianmaxiong.com/sqx_fast/
```

**连自己电脑上的服务端时**，整行改成：

```text
VITE_API_BASE_URL=http://127.0.0.1:9188/sqx_fast/
```

注意末尾有一个斜杠 `/`。`127.0.0.1` 就是你这台电脑，`9188` 是服务端端口，`sqx_fast` 是服务端配置里的访问路径。保存。

继续看线上后台数据时，可以保持原来的 `https://luyingzladmin.xianmaxiong.com/sqx_fast/`。那样不需要本机服务端，但登录用的是线上账号，改动也会写到线上。

`.env.production` 是打包给别人用时的地址。只在自己电脑里 `npm run dev` 时，可以先不改它。

**改完 `.env.development` 之后**，如果网站已经在运行，要先停掉再启动，修改才会生效。

---

## 第 2 步：安装依赖

从 Gitee/GitHub 下载或克隆的代码**不会自带** `node_modules` 文件夹，这是正常的。依赖需要在你自己的电脑上用下面命令安装一次；以后只有升级了项目依赖、或删过 `node_modules` 时才需要再装。

在 **`luyingzulin_admin`** 文件夹里打开 PowerShell（在文件夹空白处按住 Shift，右键，选「在终端中打开」），执行：

```powershell
npm install
```

第一次可能要几分钟到十几分钟。结束时没有红色 `npm ERR!`，并且这个文件夹里出现 **`node_modules`**，就成功了。`node_modules` 是自动下载的依赖，不用打开，也不用改。

---

## 第 3 步：启动网站

还是在 **`luyingzulin_admin`** 文件夹里执行：

```powershell
npm run dev
```

窗口里会出现本地地址。默认端口是 **5173**。没有自动打开时，手动打开：

http://localhost:5173

浏览器应进入「**管理员登录**」。页面上有三个输入项：管理员账号、密码、验证码。验证码是一张图片，看不清就点图片换一张。图片来自本机服务端。图片是裂的，或一片空白，说明第 1 步的地址不对，或服务端没有启动。

这个 PowerShell 窗口也要**一直开着**。关掉后，浏览器里的后台就打不开了。

---

## 怎样算成功

使用数据库里的管理员账号登录。很多基础库的初始账号是 **`admin`**，密码是 **`123456`**。登录成功后进入「**数据统计**」。页面上能看到今日订单、今日成交额、租赁中、待处理等数字，左侧能看到菜单，例如**分类管理、商品管理、订单管理、入驻审核、系统配置**。

某个菜单没有出现，是这个账号的角色里没勾选它。用有权限的账号登录后，到「**角色管理**」里勾上，再重新登录。

数字是 0、订单列表是空的，不代表后台没连上。用户还没在用户端下单时，这里就是空的。

---

## 打包给别人访问（可选）

只在自己电脑里看，可以不做这一步。

要生成可以放到服务器上的网页文件时，先把 **`.env.production`** 里的 `VITE_API_BASE_URL` 改成你的服务端公网地址（末尾带 `/`），再在 `luyingzulin_admin` 里执行：

```powershell
npm run build
```

完成后，网页文件在 **`luyingzulin_admin/dist`**。把这个文件夹放到网站服务器上。**服务端仍然要单独运行**，打包不会把服务端一起打进去。

## 常见问题

**`npm` 不是内部或外部命令**  
Node.js 没装好，或安装后没有重新打开 PowerShell。

**`npm ERR!` 且提示网络超时**  
依赖下载被网络拦住了。换一个网络，或稍后再执行一次 `npm install`。已经出现一半的 `node_modules` 可以留着，再执行一次安装即可。

**浏览器打不开 localhost:5173**  
看 `npm run dev` 的窗口是否还在。窗口里如果写的是别的端口，用窗口里打印的那个地址。配置里的 `host` 是 `0.0.0.0`，本机用 `localhost` 或 `127.0.0.1` 都能开。

**验证码不显示，或登录提示网络错误**  
服务端没启动，或 `.env.development` 的地址不是 `http://127.0.0.1:9188/sqx_fast/`。按键盘 `F12`，点「网络」或 Network，再点一次登录。请求地址应包含 `127.0.0.1:9188`。如果仍发到 `luyingzladmin.xianmaxiong.com`，说明第 1 步没有保存，或改完后没有重新执行 `npm run dev`。改完后在运行窗口按 `Ctrl+C` 停掉，再执行一次 `npm run dev`。

**`Port 5173 is in use`**  
5173 已被占用。关掉之前的管理端窗口再启动。

**登录提示验证码不正确**  
图片上的字要和输入完全一致，区分大小写。点图片换一张再试。服务端窗口如果已经关掉，验证码对了也登不进去。

**登录提示账号或密码错误**  
验证码已经通过，但数据库里没有这一组管理员。`admin` / `123456` 只在基础库自带这个账号时才能用。换库里实际的管理员账号。

**登录进去了，左侧几乎没有菜单**  
这个账号的角色没有分配菜单。需要一个已经有「角色管理」权限的账号，把菜单勾给这个角色，然后退出重新登录。
