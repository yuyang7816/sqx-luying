# 用户端运行教程

按顺序做。这是给**手机和电脑网页**用的应用，应用名称是「**露营装备租赁**」。底部有四个按钮：**首页、分类、租物车、我的**。代码在 **`luyingzulin_uniapp`** 文件夹。

先按 [服务端运行教程](服务端-运行教程.md) 准备数据库并启动服务端。首页上的装备、轮播和分类都来自这个库。服务端没启动时，页面也许能打开，但列表是空的，登录会失败。

只想先看线上已经做好的页面时，可以不启动本机服务端，保持下面「方式 B」里的线上地址。那样看到的是线上数据，不是你自己数据库里的数据。

---

## 开始之前要准备什么

你需要下面至少一种方式来运行用户端：

| 方式 | 适合谁 | 还要装什么 |
|---|---|---|
| **方式 A：命令行（推荐联调）** | 已经会一点电脑操作、要和本机服务端联调 | Node.js 18+（和管理端相同） |
| **方式 B：HBuilderX** | 更习惯图形界面、要跑微信小程序 | HBuilderX 正式版 |

**Node.js** 安装：https://nodejs.org/ （若管理端已装过 18+，这里可跳过）

**HBuilderX** 下载：https://www.dcloud.io/hbuilderx.html  下载「正式版」。打开后窗口标题是 HBuilderX 即表示安装成功。

只在电脑浏览器里看时，**不需要**微信开发者工具。要在微信里看，再安装微信开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

仓库里**没有** `luyingzulin_uniapp/node_modules`。无论用命令行还是 HBuilderX，**第一次运行前**都要在 `luyingzulin_uniapp` 目录执行 `npm install`（见第 1 步方式 A 或第 2 步说明）。

---

## 第 1 步：确认连的是自己电脑上的服务端

用户端通过 **`common/env.js`** 读取接口地址。实际值来自项目根目录的环境文件（`.env.development` 或 `.env.integration`）。

### 方式 A：本机联调（推荐）

1. 用记事本或 VS Code 打开 **`luyingzulin_uniapp/.env.integration`**（没有就复制 `.env.development` 改名为 `.env.integration` 再改）。
2. 确认内容类似下面（端口和服务端一致即可）：

```text
VITE_USE_MOCK=false
VITE_API_BASE_URL=/sqx_fast/
VITE_API_PROXY_TARGET=http://127.0.0.1:9188
VITE_DEV_PORT=5573
```

含义说明（不用改代码，理解即可）：

- 浏览器访问的是 **`http://localhost:5573`**
- 页面请求 `/sqx_fast/...` 时，开发服务器会自动转发到 **`http://127.0.0.1:9188`**，也就是你本机刚启动的服务端。

3. 在 **`luyingzulin_uniapp`** 文件夹打开 PowerShell，先装依赖（第一次要做）：

```powershell
npm install
```

4. 启动 H5：

```powershell
npm run dev:integration
```

控制台出现本地地址后，用浏览器打开，一般是：

http://localhost:5573

### 方式 B：继续看线上演示

打开 **`luyingzulin_uniapp/.env.development`**，保持：

```text
VITE_API_BASE_URL=https://luyingzl.xianmaxiong.com/sqx_fast/
```

然后用 HBuilderX 运行到浏览器，或 `npm run dev:h5`（若已配置）。此时**不需要**本机服务端，但数据是线上的。

### 方式 C：不用代理，直接写死本机地址

把 **`.env.development`** 里的 `VITE_API_BASE_URL` 改成：

```text
VITE_API_BASE_URL=http://127.0.0.1:9188/sqx_fast/
```

保存后重新运行。这种方式不经过 Vite 代理，服务端必须允许跨域或同机访问。

## 第 2 步：用 HBuilderX 打开项目（可选）

如果选用 HBuilderX 而不是命令行：

1. 打开 HBuilderX。
2. 菜单选「文件」→「打开目录」。
3. 选中 **`luyingzulin_uniapp`** 这个文件夹。不要选它的上一级（那一层还有 `luyingzulin_server` 和 `luyingzulin_admin`），也不要只选里面的某个页面。
4. 左侧能看到 `pages`、`packageGoods`、`packageOrder`、`pages.json`、`manifest.json`、`common`。

按钮、输入框、轮播用的是 **uView Plus**。如果运行后控件没有样式，先在 `luyingzulin_uniapp` 里执行一次 `npm install`，把组件装全，再回到 HBuilderX 运行。

---

## 第 3 步：在电脑浏览器里运行

**命令行方式：** 见第 1 步方式 A，执行 `npm run dev:integration` 后打开浏览器。

**HBuilderX 方式：**

1. 菜单选「运行」→「运行到浏览器」→「Chrome」。没有 Chrome 时选 Edge。
2. 第一次会下载编译器，底部控制台会出现「正在编译」。等到出现「编译成功」，浏览器会自己打开。
3. H5 开发端口在 **`manifest.json`** 和 **`.env.integration`** 里是 **5573**（命令行联调时以控制台打印为准）。
4. 打开后标题应是「**露营装备租赁**」。底部应能看到 **首页、分类、租物车、我的**。

**HBuilderX 或命令行窗口不要关。** 关掉后页面会打不开。

电脑浏览器比较宽时，页面会显示在中间一条手机宽度的区域。这是正常的，它本来就是手机页面。

---

## 第 4 步：在微信小程序里运行（可选）

电脑浏览器已经能看，可以先不做这一步。

1. 安装并打开一次微信开发者工具，用微信扫码登录。
2. 在微信开发者工具里打开「设置」→「安全设置」，打开服务端口。
3. 回到 HBuilderX，菜单「工具」→「设置」→「运行配置」，把微信开发者工具的安装路径填上。
4. 菜单「运行」→「运行到小程序模拟器」→「微信开发者工具」。

`manifest.json` 里 `mp-weixin` → `appid` 已经写了一个小程序号码。你不是该小程序的开发成员时，微信会提示 AppID 没有权限。自己练习时，把这个 `appid` 改成**你自己的**小程序 AppID，或继续只用浏览器运行。

微信小程序里的登录方式和浏览器不一样：可能走「微信授权登录」和「授权手机号」。这需要你自己的小程序已经开通手机号能力，并在管理端「系统配置」里填好小程序 AppId 和密钥。**浏览器里练习时，用手机号验证码或密码登录即可。**

微信开发者工具里如果提示域名不合法，本地调试可以勾选「**不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**」。`127.0.0.1` 不是微信后台配置过的合法域名，不勾选这一项，模拟器里的接口会失败。

选城市、门店相关能力会用到**腾讯地图**密钥。密钥写在 `manifest.json` 的 H5 地图配置里，也要在管理端地图配置里填写。没有密钥时，首页和下单仍能打开，定位和地图导航可能失败。申请地址见 [用户端功能说明](用户端-功能说明.md) 末尾。

## 怎样算成功

首页能打开，底部四个按钮能点。首页应能看到搜索框（例如「搜索帐篷、天幕、营地车」）、轮播或活动区，以及「租赁套餐 / 小时租 / 整日租」等 Tab。数据库里已有商品时，下面会出现装备卡片和价格。

按键盘 **F12**，点「网络」或 Network，再刷新页面。

- **本机联调**（`npm run dev:integration`）：请求会先到 `localhost:5573`，再代理到 `127.0.0.1:9188`。
- **直连线上**：请求域名是 `luyingzl.xianmaxiong.com`。

库里没有商品时，列表可能是空的。这表示页面已经通了，只是数据库里还没有数据。要在管理端「**分类管理」「商品管理**」里添加，或确认 `lyzl.sql` 已经导入成功。

用手机号注册需要短信。短信密钥没配时，点「获取验证码」会失败。可以先用数据库里已经有的测试用户和密码登录。密钥申请见 [用户端功能说明](用户端-功能说明.md) 末尾。

## 常见问题

**运行菜单是灰的，或提示没有浏览器**  
先安装 Chrome 或 Edge，再重启 HBuilderX。项目必须用「打开目录」打开 `luyingzulin_uniapp`。

**一直停在「正在编译」，或浏览器是白屏**  
等控制台不再滚动。若出现红色报错，把第一行红色文字保留下来。常见原因是打开的文件夹不对，或 `npm install` 没执行完。公司网络拦截下载时，换一个网络再运行一次。

**首页能开，但没有装备，登录失败**  
服务端没有启动，或环境文件仍指向线上而你想看本机数据。先看服务端窗口是否还有「露营租赁项目启动成功...」，再按第 1 步改 `.env.integration` 并重新 `npm run dev:integration`。

**分类页是空的**  
`rent_category`、`rent_goods` 表里没有数据。到管理端新增分类和商品，或重新导入 `lyzl.sql`。

**点上传后图片没保存**  
管理端「系统配置」里的图片存储还没配好。可以先选**本机硬盘**。选了阿里云又没填密钥时，上传会失败。

**微信开发者工具提示 AppID 无效或没有权限**  
换成你自己的小程序 AppID，或改用浏览器运行。

**租物车提示要先登录**  
未登录时租物车会显示「登录后查看租物车」。在「我的」里登录后再看。

**定位一直显示「定位中」**  
浏览器拦住了位置权限。可以在地址栏允许定位，也可以直接点左上角城市手动选择。不影响先看装备列表。
